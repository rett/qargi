# In a Codex run
qargi publishes your last message as OUT/report.md when the run ends, over any report.md there, so make your final message the whole report. Your commands run in the Codex sandbox with no network: fetch, install and push nothing. If CLONE, CONTRACT or OUT is not there for your commands, stop and report BLOCKED naming the path: never work without the contract. A write run may write CLONE, its `.git` and OUT: commit and collect your work as the contract says, since changes left uncommitted with no patches are a refusal (BLOCKED), never DONE. A read-only run may write nothing, OUT included, so its final message is all it returns, and qargi writes OUT/manifest.json beside it. Your MCP tools are the ones your run's configuration lists, and no others.
