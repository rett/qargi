# In a Codex run
qargi publishes your last message as OUT/report.md when the run ends, over any report.md there, so make your final message the whole report. Your commands run in the Codex sandbox with no network: fetch, install and push nothing. A write run may write CLONE and OUT; a read-only run may write nothing, OUT included, so its final message is all it returns, and qargi writes OUT/manifest.json beside it. Your MCP tools are the ones your run's configuration lists, and no others. Not verified: that the sandbox lets git write `.git`; when a commit is refused, say so in the report and leave the change in CLONE.
