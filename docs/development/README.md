# Development

Changing qargi itself.

- [CONTRIBUTING.md](../../CONTRIBUTING.md): branching (git-flow), layout, tests and the suite, changing the canon, versioning, changes and the changelog, adding a runtime with no code, adding a runtime to qargi itself.
- [AGENTS.md](../../AGENTS.md): the development environment for coding agents and contributors.
- The command line is described once, in `lib/commands.py`; see [Help, manual page and completion](../reference/README.md#help-manual-page-and-completion) for what is generated from it.
- Running a branch checkout: [Running a branch checkout](../install-and-upgrade/README.md#running-a-branch-checkout).

To set up a checkout of this repository for development, preview with `make -n bootstrap`, install with `make bootstrap` and verify with `make doctor`; see `AGENTS.md`, Development environment.
