# dev reference index

What the dev role follows, on top of `shared/INDEX.md`. Paths are relative to `roles/dev/`.

| Path | Purpose | Load |
|---|---|---|
| rules/rules.md | working rules beyond the contract | always |
| workflow/workflow.md | task lifecycle and definition of done by kind of change | when starting a task |
| conventions/code.md | idioms, naming, errors, security habits | when writing code |
| conventions/changes.md | checklist for a change users can see | when a change is visible to users |
| conventions/commits.md | commit message shape | when committing |
| review/checklist.md | self-review before reporting | before the final report |
